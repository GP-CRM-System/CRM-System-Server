# Product Performance

```json
db.getCollection('orders').aggregate(
  [
    { $unwind: '$products' },
    {
      $group: {
        _id: '$products.name',
        sales: { $sum: '$products.quantity' },
        revenue: {
          $sum: {
            $multiply: [
              '$products.quantity',
              '$products.unitPrice'
            ]
          }
        }
      }
    },
    {
      $project: {
        _id: 0,
        name: '$_id',
        sales: 1,
        revenue: 1
      }
    },
    { $sort: { sales: -1 } }
  ],
  { maxTimeMS: 60000, allowDiskUse: true }
);
```
